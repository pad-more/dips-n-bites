# dips.n.bites

Static preview site for dips.n.bites, a cake bakery in East Legon, Accra.

- `index.html`, `app.js`: the site (no build step)
- `logo.webp`, `menu.webp`: images

Prices, contact details, hours and story copy are still placeholders. The page is set to `noindex` until launch: remove the robots meta tag in `index.html` when going live.
